## 📖 Project Overview

A complete, fully functional, multi-page personal memories website developed for **CS111 (Introduction to Computing)**. 

This website is built strictly adhering to standard, semantic **HTML5 only**—no CSS, no JavaScript, no Bootstrap, and no external frameworks. It features an eight-category folder-style homepage (`index.html`) linking to eight dedicated content pages showcasing personal memories, loved ones, friends, favorite dishes, movies, songs, and humor.

## 🛠️ Technology & Guidelines

- **HTML5 Semantic Elements:** `<header>`, `<main>`, `<section>`, `<nav>`, `<footer>`, `<figure>`, `<figcaption>`, `<ul>`, `<ol>`, `<li>`, `<table>`, `<audio>`, `<video>`.
- **Pure HTML Requirement:** 
  - ❌ Zero CSS files or `<style>` blocks.
  - ❌ Zero inline `style="..."` attributes.
  - ❌ Zero JavaScript scripts or external libraries.
- **Media Support:** Native browser `<audio controls>` and `<video controls>` with relative asset paths.

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/ZyronNeil2007/zbautista_cs111.git
   ```
2. Navigate into the project folder:
   ```bash
   cd zbautista_cs111
   ```
3. Open `index.html` in any web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari) by double-clicking it.
