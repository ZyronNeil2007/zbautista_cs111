Information architecture

Navigation & user flow

Keep global navigation available throughout the page. Dedicated memory collections should also offer a consistent route back to the homepage.

Navigation ruleFolder links open the existing collection pages. About, journey, work, and contact links scroll to their homepage sections. Keep link labels descriptive, preserve visible focus, and make the mobile navigation easy to reach.

Section breakdown

Purpose of each section

Header & navigation

Establishes identity, provides direct section links, folder search, and a prominent route into the memories.

Hero & introduction

Explains the site's personal purpose immediately and offers browse-first and learn-more actions.

Memory folders

Primary content hub; eight scannable cards link to the dedicated memory and interest pages.

About & journey

Adds creator context and a simple timeline so visitors can understand the person behind the archive.

Selected work & gallery

Highlights portfolio projects and offers a small visual preview without duplicating entire collections.

Contact & footer

Provides a final contact action, social destinations, secondary navigation, and ownership details.

Responsive & accessibility notes: Desktop uses four-column memory cards; tablet reduces the grid to two columns; mobile stacks sections and turns cards into compact image-and-text rows, with all main navigation links visible in a horizontally scrollable row. Keep meaningful heading order, descriptive image alt text, keyboard-visible focus, labeled form fields, sufficient grayscale contrast, and touch-friendly controls.
